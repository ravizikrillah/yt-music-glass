Permanent Offline Lyrics Vault synced with YouTube Music Downloads

Open your YouTube Music Downloads page or click Download on any track, album, or playlist while online. YT Music Glass detects your offline library in the background and permanently pins synced LRC lyrics and active translations to local storage.

Three-tier resilient matching (trackKey → videoId → normalized artist + title) resolves your songs cleanly when Wi-Fi is off, paired with macOS Control Center and AirPods media controls.

Install in 30 seconds

Download the standalone macOS DMG or compile directly from source with Xcode Command Line Tools.

01

Download & Drag to Applications

Download the latest YT-Music-Glass-macOS-arm64.dmg, open it, and drag YT Music Glass.app into your Applications folder.

02

First-Launch macOS Gatekeeper

Since this is a free open-source release without a paid Apple Developer ID, right-click the app and choose Open, or clear quarantine once in Terminal:

xattr -cr "/Applications/YT Music Glass.app"
03

Or Build Directly From Source

Zero Node.js or CocoaPods required. Compile on macOS 14+ with Apple Command Line Tools:

git clone https://github.com/ravizikrillah/yt-music-glass.git && cd yt-music-glass && make install

Frequently asked questions

Why build YT Music Glass in Swift instead of Electron?

Electron bundles a full Chromium and Node.js runtime with every app, taking 180 to 250 MB on disk. YT Music Glass uses macOS's built-in WebKit (WKWebView) paired with native SwiftUI and AppKit panels, keeping the installer at 2.9 MB while enabling true transparent click-through HUDs, Menu Bar live lyrics, and native media keys.

Is my Google / YouTube Music sign-in safe?

Yes. You sign in directly on official music.youtube.com inside macOS's standard WKWebView data store. YT Music Glass never reads, transmits, or stores your credentials on any external server, and every line of Swift source code is open on GitHub.

How do automatic updates work?

The app checks the public GitHub Releases API for ravizikrillah/yt-music-glass. When a new version tag is published, click Check for Updates in the app menu or About window to stream the latest .dmg directly to your Downloads folder and mount it automatically.

Can I switch between YouTube Music's Roboto font and macOS SF Pro?

Yes. Open Settings (⌘,) or Command Palette (⌘K) to switch live between bundled Roboto and Apple's native SF Pro across both the lyrics panels and the YouTube Music web interface.
