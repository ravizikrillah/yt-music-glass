Crafted for how you actually listen on MacBook.

Every detail blends into macOS instead of fighting it—from live lyrics in your Menu Bar to instant keyboard navigation.

Three-tier karaoke lyrics with offline Auto-Romaji & Smart Translate

Sing along to Korean, Japanese, Mandarin, or English tracks effortlessly. Non-Latin lines show compact original script above bold word-flow pronunciation, powered 100% offline via Revised Romanization and Apple CoreFoundation tokenizers.

Turn on Smart Translate to pick any source and target language—translations automatically hide whenever a song (or individual line) already matches your language.

Original But you DM me, “니가 궁금해서”
Romaji But you DM me, “niga gunggeumhaeseo”
Translate Tapi kamu DM aku, “karena aku penasaran padamu”
Pure Indonesian song while Target = ID? Translation stays hidden automatically.

Docked resizable sidebar, Transparent Floating HUD & Mini Player

Keep lyrics docked neatly on the right side with a smooth draggable divider, pop them out into a true-transparent click-through overlay (`0%–85%` opacity) that floats above VS Code or full-screen apps, or switch to the compact Mini Player (`⇧⌘P`) while you work.

Enable Menu Bar Live Lyrics (`⇧⌘B`) to follow the active line right next to your top macOS status bar without opening any window at all.

Install in 30 seconds

Download the signed-free indie macOS DMG or build directly from source with Xcode Command Line Tools.

1

Download & Drag to Applications

Download the latest YT-Music-Glass-macOS-arm64.dmg, open it, and drag YT Music Glass.app into your Applications folder.

2

First-Launch macOS Gatekeeper

Since this is an independent open-source release without a paid Apple Developer ID, right-click the app and choose Open—or clear quarantine in Terminal:

xattr -cr "/Applications/YT Music Glass.app"
3

Or Build Directly From Source

Zero Node.js or CocoaPods needed—just macOS 14+ and Apple Command Line Tools:

git clone https://github.com/ravizikrillah/yt-music-glass.git && cd yt-music-glass && make install

Frequently asked questions

Why build YT Music Glass in Swift instead of Electron?

Electron ships a separate Chromium runtime with every app, easily taking 180–250 MB on disk and high idle memory. YT Music Glass uses macOS's native WebKit (WKWebView) paired with native SwiftUI and AppKit windows, keeping the complete installer around 2.9 MB while supporting true transparent click-through HUDs, Menu Bar lyrics, and native media keys.

Is my Google / YouTube Music sign-in safe?

Yes. You sign in directly on official music.youtube.com inside macOS's standard WKWebView data store. YT Music Glass never reads, transmits, or stores your password or cookies on any third-party server, and the full Swift source code is open for inspection on GitHub.

How do automatic updates work?

The app periodically checks the public GitHub Releases API for ravizikrillah/yt-music-glass. When a newer tag is published, you can click Check for Updates in the App Menu or About window to download and open the latest .dmg directly.

Can I switch between YouTube Music's Roboto font and macOS SF Pro?

Yes. Open Settings (⌘,) or Command Palette (⌘K) to switch live between YouTube Music's bundled Roboto and Apple's native SF Pro across both the lyrics panels and the YouTube Music interface.
